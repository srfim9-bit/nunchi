# APK

release APK(약 39MB)는 GitHub 웹 업로드 한도(파일당 25MB)를 넘어, 이 폴더 대신 저장소의 **[Releases](../../../releases)**에 올렸습니다.

- 파일명: `팀명_NUNCHI_release.apk` 형식 (release 빌드, 버전 0.5.4)
- 설치: Pleos Connect 에뮬레이터를 켠 뒤 APK를 에뮬레이터 창에 끌어다 놓습니다.
- 직접 빌드: 저장소 루트에서 `gradlew :app:assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
